Native, not a tab

A real app, drawn by itself.

Zeus links to your phone the way WhatsApp Web does, then draws every chat itself. Replies, reactions, voice notes, files and link previews live in one quick window.

Light and dark

Bright by day, dark by night.

Zeus follows your system and turns over in one stroke: wallpaper, bubbles and all. Drag across the window to see both.

Nine themes, any accent.

The Zeus, WhatsApp and Messages looks and six ready-made themes, each light or dark, with an accent of your own on top. The same card as the app's Settings. Try a few on the window.

The Windows installer is not code-signed, so SmartScreen warns once: choose More info, then Run anyway. The Mac app is not signed by Apple either, so the first time, right-click Zeus in Applications and choose Open. The macOS and Linux builds come from GitHub Actions; please report what you find.
